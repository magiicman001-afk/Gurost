# DESIGN.md format reference (one example only)

`EXAMPLE-kraken-DESIGN.md` is copied unchanged from github.com/VoltAgent/awesome-design-md (MIT licence, Copyright (c) 2026 VoltAgent). It is here ONLY to show the **format** of a DESIGN.md: colour palette, typography, components, layout, depth, do's and don'ts, responsive behaviour, agent prompt guide.

Rules for Gurost:
- Use the format to write one DESIGN.md per Gurost industry from `docs/INDUSTRY_PALETTES_SPEC.md` (a later step).
- Never ship a look-alike of a real brand. The tokens in the example are public CSS values; the brand identity belongs to its owner.
- Do not add more brand files to the repo.
