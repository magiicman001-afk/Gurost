# Design data attribution

`products.csv`, `colors.csv` and `typography.csv` are copied unmodified
from UI/UX Pro Max (npm package `ui-ux-pro-max-cli`, v2.15.0), which is
distributed under the MIT License.

To refresh them, run `npx ui-ux-pro-max-cli init --ai claude` and copy
the same three files from `.claude/skills/ui-ux-pro-max/data/`.
